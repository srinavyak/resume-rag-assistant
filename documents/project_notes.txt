=== Netflix GPT (Personal Project) ===
Live demo: https://movieplex-72886.web.app/
Stack: React, Redux, Firebase, TMDB API, Google Gemini API
Timeframe: Built during career break, 2023–Present

Netflix GPT is a full-stack, Netflix-style movie discovery web application. Users can
search for movies using natural language (e.g., "something light and funny in Spanish")
instead of exact titles or keywords. The app integrates the Google Gemini API to interpret
the user's intent and generate personalized, multi-language movie recommendations, which
are then matched against real movie data pulled from the TMDB API.

Key implementation details:
- Built reusable React components (Movie List, Movie Card, Main/Secondary Containers) and
  custom hooks to fetch and manage movie data from the TMDB API.
- Designed Redux state-management slices to coordinate user, movie, and AI-suggestion data
  across the application.
- Implemented secure authentication using Firebase Auth, including login/signup, form
  validation, profile updates, and protected routes.
- Applied prompt/context engineering to the Gemini API calls so recommendations stay
  relevant to the user's natural-language query and support multiple languages.
- Optimized performance using memoization and delivered a fully responsive UI.
- Deployed to production using Firebase Hosting, managing environment configuration and
  resolving authentication and profile bugs post-launch.

This project is the main evidence of hands-on, production LLM API integration —
prompt engineering, structured output handling, and owning an app end-to-end from
build through live deployment.
